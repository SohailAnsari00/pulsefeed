# ⚡️ PulseFeed – Stay Ahead of the Curve 🌐

Welcome to **PulseFeed**, your modern web hub for curated news at the intersection of **technology**, **geopolitics**, and **innovation**. Tailored for tech-savvy minds, PulseFeed delivers real-time updates without the noise of entertainment fluff.

---

## 🚀 Features

✨ **Minimalistic UI**  
A sleek and responsive design powered by HTML, CSS, and JavaScript — optimized for speed and readability.

🔍 **Smart Search**  
Built-in search bar lets users instantly find articles by keyword or topic.

📰 **Category-Based Navigation**
- 📱 **Technology**
- 🌍 **Geopolitics**
- 💡 **Innovation**
- 🚀 **Startups**

📱 **Mobile-Friendly PWA**  
Installable as a Progressive Web App (PWA) with an app-like experience on mobile devices.

🎯 **Curated Content**
Focused on **technology**, **economic trends**, and **innovative startups**, leaving out entertainment distractions.

⚙️ **Loading Animation**  
Smooth loading indicators enhance user experience while fetching content.

---

## 🧩 Tech Stack

- **HTML5 & CSS3**
- **Vanilla JavaScript**
- **Google Fonts**
- **Manifest + PWA support**

## 🛠 Setup Instructions

1. Clone the repo:

   ```bash
   git clone https://github.com/yourusername/pulsefeed.git
   ```
2. Navigate into the project:

   ```bash
   cd pulsefeed
   ```
3. Run it locally (use VS Code Live Server or any static server):

   ```bash
   live-server
   ```
